Getting Started

Adding a Host

Tap the + button on the host list screen. Enter your hostname or IP address, port (default 22), and username. Your password is stored securely in the iOS Keychain.

Connecting

Tap a host to connect. On first connection, you'll be asked to verify the server's SSH fingerprint. Accept to save it — SSHOpen will verify it on all future connections.

Using Snippets

Tap Snippets in the toolbar to open your saved commands. Tap any snippet to run it instantly. Use the + button to add new ones.

Ctrl & Special Keys

The custom keyboard row above the system keyboard provides esc, ctrl, tab, arrow keys, and function keys. Tap ctrl then a letter to send Ctrl combinations (e.g. ctrl+c to interrupt a process).

FAQ

Connection fails immediately

Check that your SSH server is running and reachable. If connecting over a VPN (e.g. Tailscale), ensure the VPN is active before tapping Connect. Verify the hostname and port are correct.

Fingerprint mismatch warning

This means the server's SSH key has changed since your last connection. If you recently reinstalled your OS or regenerated SSH keys, clear the saved fingerprint in Settings and reconnect to re-verify.

Interactive apps (vim, htop, tmux) don't display correctly

Make sure your TERM environment variable is set to xterm-256color on the server. You can set this in your ~/.bashrc or ~/.zshrc: export TERM=xterm-256color

Where is my password stored?

All passwords are stored in the iOS Keychain — the same secure storage used by Safari and other system apps. They are never transmitted anywhere other than your SSH server during authentication.

Can I use SSH keys instead of a password?

SSH key authentication is planned for a future release.

Privacy

SSHOpen does not collect, transmit, or store any personal data. All connection credentials are stored locally in the iOS Keychain. No analytics, no tracking, no third-party SDKs.
